# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in Tayari, please do **NOT** open a public issue.

Please send an email to `security@tayari.ai` with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will respond within 48 hours and provide updates on resolution status.
