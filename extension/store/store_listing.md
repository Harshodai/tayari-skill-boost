# Tayari Job Companion — Chrome Web Store Listing Copy

## Short Description (max 132 chars)
Detect jobs, autofill ATS applications in Review Mode, and track your job search with Tayari AI on your own hardware.

## Detailed Description
Tayari Job Companion is your privacy-first, self-hostable job search assistant.

### Features
- **Tier-A ATS Autofill**: Fill job application forms on Greenhouse, Lever, Ashby, and Workday with high precision.
- **Review Mode Safety**: Tayari NEVER auto-submits your applications without your explicit review. Every fill is transparent.
- **One-Click Job Detect**: Save job postings from LinkedIn, Indeed, Greenhouse, and Lever directly to your Tayari Interview Board.
- **Inline Match Scoring**: View real-time ATS keyword matching and skill gap insights directly on job posting pages.
- **Self-Hosted First**: Connect directly to your local or private Tayari instance via API key.

## Privacy Practices Disclosure
- **User Data Collection**: Tayari collects resume details, job search preferences, and target application URLs strictly to execute user-initiated autofill and tracking.
- **Data Sharing**: Data is stored locally or transmitted solely to your designated Tayari instance. No third-party ad tracking or selling of personal data.
- **Permissions Justification**:
  - `storage`: Saves user backend URL in browser sync and API key in local non-synced browser storage.
  - `activeTab` & `tabs`: Detects job posting page metadata when the user interacts with the extension.
  - `notifications`: Alerts users when background autofill packages or review queue items are ready.
