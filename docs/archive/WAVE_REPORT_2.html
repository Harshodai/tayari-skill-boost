Mission M5: Email→Kanban Closed Loop

  • Classifier & Matcher Pipeline: Enhanced email_classifier.py to calculate confidence scores and match incoming emails against existing user applications with fuzzy logic.
  • Reversibility & Confidence Threshold: Enforced strict 0.8 confidence threshold: matches below 0.8 yield a needs_review suggestion instead of auto-moving.
  • PII Redaction: Integrated redact_pii_content using pii_detector.py to scrub sensitive identifiers from email bodies before processing.
  • Test Suite: Created tests/test_email_classifier.py containing 10 email fixtures across all stages, matcher precision tests, and PII redaction checks (6 tests passed).

Mission M6: Ghost-Job & Legitimacy Signals

  • Posting Health Calculator: Updated legitimacy_checker.py to compute composite Posting Health badges (Fresh, Aging, Likely ghost) with transparent evidence signals (age, ATS source trust, salary transparency, repost count).
  • UI Filter & Badge Integration: Updated src/pages/JobSearch.tsx to filter out Likely ghost postings when the "Hide likely-ghost jobs" toggle is active.
  • Ranker Stability: Added unit tests proving RRF ranker stability when health rank weight is 0. The pytest tests/ -k "hermes or legitim" selection executed 42 passing tests. Frontend production build succeeded in 2.91s.

Mission M7: Personalization Spine

  • Unified Profile Service: Built profile_service.py exporting UserCareerProfile schema (roles, locations, salary floor, preferred tone, blacklist, writing style fingerprint).
  • Guardrail-Level Protection: Implemented check_do_not_apply to prevent AutoPilot from queueing blacklisted companies regardless of UI state.
  • Writing Style Feedback: Implemented log_style_delta to record user edit signals in an append-only fingerprint for memory_composer. All 5 tests in test_profile_and_memory.py pass.
